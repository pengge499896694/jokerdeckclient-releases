# Jokerdeck Client 下载

本仓库仅发布 Windows x64、macOS Apple Silicon 和 Intel 安装包，不包含客户端源码。

请从 [Releases](../../releases/latest) 下载。客户端通过 Release 附件 `v2-latest.json` 检查更新，通过 `announcement.json` 读取公告。

维护公告时，编辑 `announcement.json` 的 `title`、`content`、`updatedAt`。`content` 为纯文本，可填写 IP 映射步骤；客户端只展示内容，由用户自行决定是否操作。

安装包自动发布由私有源码仓库的 CI 负责。下载不需要 GitHub 账号。
